# Скрипт проверки кодов участников Всероссийской олимпиады школьников

## Описание

Этот скрипт автоматизирует проверку кодов участников Всероссийской олимпиады школьников в [Резервной тестирующей системе](https://online.olimpiada.ru). Он считывает коды из Excel-файла, отправляет их на сайт, проверяет результаты по имени участника и формирует отчет с баллами.

## Возможности

- Проверка кодов для конкретного класса и предмета.
- Поддержка режима поиска первого совпадения или формирования полного отчета.
- Возможность логирования действий для отладки (DEBUG режим).
- Автоматическое формирование отчета в Excel с результатами проверки.
- [НОВОЕ]: Парсинг таблицы с проходными баллами с [официального сайта олимпиады](https://vos.olimpiada.ru/2025/school/score).
- [НОВОЕ]: Автоматическое определение награды и статуса участника (см. [чуть ниже](#новые-возможности-в-версии-20))

### Новые возможности в версии 2.0

Скрипт теперь автоматически парсит таблицу с проходными баллами с официального сайта и определяет награду каждого участника: Победитель, Призер или Участник, а также статус: Прошел, Не прошел или Не участвовал.

## Требования

- Python 3.9+
- Браузер Google Chrome
- Файл с кодами в формате Excel (.xlsx) с определенной структурой (см. [пример](example_codes.xlsx))

## Зависимости

Устанавливаются через pip:

```bash
pip install pandas selenium openpyxl webdriver-manager
```

## Настройки

Настройки указываются в начале скрипта:

| Переменная    | Описание                                                                                                     | Пример                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| EXCEL_PATH    | Путь к Excel-файлу с кодами                                                                                  | example_codes.xlsx                                         |
| SITE_URL      | URL сайта олимпиады (скрипт рассчитан только на этот сайт)                                                    | [https://online.olimpiada.ru](https://online.olimpiada.ru) |
| SCORE_TABLE_URL | URL таблицы с проходными баллами (скрипт рассчитан только на этот сайт)                                     | [https://vos.olimpiada.ru/2025/school/score](https://vos.olimpiada.ru/2025/school/score) |
| LOG_LEVEL     | Уровень логирования (DEFAULT или DEBUG)                                                                      | DEFAULT                                                    |
| SEARCH_MODE   | Режим проверки: FIRST_MATCH — останавливается после первого совпадения, REPORT — собирает отчет (Excel-файл) | FIRST_MATCH                                                |
| HEADLESS      | Запуск Chrome без окна                                                                                       | False                                                      |
| WAIT_TIMEOUT  | Таймаут ожидания элементов на странице (сек.)                                                                | 10                                                         |
| SLEEP_BETWEEN | Задержка между проверками (сек.)                                                                             | 1.0                                                        |
| TARGET_CLASS  | Класс участника для проверки                                                                                 | 8Б                                                         |
| TARGET_NAME   | Имя и фамилия участника для проверки                                                                         | Иван Иванов                                                |

## Использование

1. Проверьте выполнение [требований](#требования) и установите [зависимости](#зависимости)
2. Подготовьте Excel-файл с кодами участников (см. [пример](example_codes.xlsx))

   Столбцы должны содержать коды. Пример кода:

   ```bash
   abcd12/sch123456/1/ijkl56
   ```

   (Примечание: четкого формата кодов нет, нужно лишь чтобы код прошел на сайте Резервной тестирующей системы)

3. Классы участников должны быть указаны в соответствующем столбце.

4. Запустите скрипт:

   ```bash
   python check_codes.py
   ```

5. Следуйте инструкциям в консоли:
   - Введите название предмета для проверки.
   - Дождитесь окончания проверки.

В режиме `REPORT` будет создан Excel-файл с результатами.

## Формат Excel-отчета

Файл отчета содержит следующие столбцы:

- **ИФ** — имя и фамилия участника
- **Код** — проверенный код
- **Баллы** — набранные баллы в формате "X/Y" (где X - баллы участника, Y - максимальные баллы)
- **Награда** — результат участия (Победитель/Призер/Участник/Нет)
- **Статус** — статус участника (Прошел/Не прошел/Не участвовал)

## Примечания

- Скрипт использует Selenium с ChromeDriver для автоматизации браузера.
- В `HEADLESS` режиме браузер запускается без графического интерфейса, что удобно для серверов.
- Рекомендуется использовать стабильное интернет-соединение, так как скрипт взаимодействует с веб-сайтом в реальном времени.
- Если в таблице проходных баллов еще нет данных для выбранного предмета и класса, скрипт выдаст предупреждение и попробует сформировать отчет без определения статуса.
